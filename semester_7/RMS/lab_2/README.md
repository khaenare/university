# MIDI-анімація

Лабораторна робота №2, варіант 3. Програма читає MIDI-файл і створює анімацію: кожна нота стає об'єктом на екрані, а параметри об'єкта задаються параметрами ноти. Вбудований синтезатор озвучує файл, тож анімація синхронна зі звуком.

## Запуск

```
pip install -r requirements.txt
python main.py                      # демонстраційний файл assets/atlantic_breeze.mid
python main.py шлях/до/файлу.mid    # будь-який MIDI-файл зі щонайменше двома доріжками
```

Тести парсера: `python -m unittest discover -s tests -t .`

## Керування

| Клавіша | Дія |
|---|---|
| Пробіл | пуск / пауза |
| ← / → | перемотати на 5 с назад / вперед |
| 1–9 | вимкнути / увімкнути доріжку (і звук, і об'єкти) |
| клік по смузі прогресу | перейти до моменту |
| перетягнути `.mid` у вікно | відкрити інший файл |
| Esc | вихід |

## Відповідність MIDI → анімація

| Дані MIDI | Параметр анімації |
|---|---|
| Висота ноти (pitch) | координата X: низькі ноти ліворуч, високі праворуч |
| Роль доріжки | тип об'єкта: мелодія — **зірки** (вгорі), гармонія — **бульбашки** (посередині), бас — **хвиля** (внизу), ударні — **спалах фону / кільце / іскри** |
| Velocity (сила натискання) | розмір і яскравість; у бульбашок — швидкість підйому, у хвилі — амплітуда |
| note_on / note_off | поява / згасання об'єкта |
| Тривалість ноти | час життя об'єкта |
| Висота басової ноти | кількість хвиль на екрані (вищий бас — дрібніші хвилі) |
| Нота ударних | тип ефекту: бочка — спалах фону, малий барабан — кільце, хай-хет / маракаси — іскри |

Роль доріжки визначається автоматично: канал 10 — ударні; інструмент з родини General MIDI «Бас» або низький середній регістр — бас; найвища переважно одноголосна доріжка — мелодія; решта — гармонія.

Журнал «Подія MIDI → об'єкт анімації» у правому верхньому куті показує останні ноти і що з них вийшло на екрані, наприклад: `Melody: E5, vel 85 → зірка x=1033, r=23`.

## Приклади вхідних даних

Папка `examples` (створена скриптом `examples/make_examples.py`) — файли можна перетягувати у вікно програми:

| Файл | Що перевіряє |
|---|---|
| `01_ode_to_joy_format0.mid` | MIDI формату 0: одна доріжка з двома каналами → розділяється на дві; крещендо (velocity зростає) |
| `02_tempo_change.mid` | зміна темпу 70 → 140 BPM посеред файлу |
| `03_waltz_3-4.mid` | розмір такту 3/4 |
| `04_drums_and_bass.mid` | лише бас і ударні, без мелодії |
| `05_six_tracks.mid` | шість доріжок різних ролей |
| `06_one_track.mid` | одна доріжка → попередження (за умовою потрібно ≥2) |
| `07_no_notes.mid` | **некоректний:** MIDI без жодної ноти |
| `08_text_renamed.mid` | **некоректний:** текстовий файл із розширенням .mid |
| `09_truncated.mid` | **некоректний:** обрізаний MIDI-файл |
| `10_not_midi.txt` | **некоректний:** файл іншого типу |

На некоректний файл програма показує повідомлення (у вікні — червона плашка, з командного рядка — текст помилки) і не падає; поточна пісня продовжує грати.

## Структура

| Файл | Що робить |
|---|---|
| `main.py` | точка входу, аргументи командного рядка |
| `midi_anim/midi_parser.py` | читання MIDI: delta-time → абсолютні тіки → секунди з урахуванням змін темпу; пари note_on/note_off → ноти; ролі доріжок; типи ударів (спільні для звуку й анімації) |
| `midi_anim/synth.py` | синтез звуку з нот (гармоніки + обвідна, ударні — шум і синус зі спадною частотою), окремий звук для кожної доріжки |
| `midi_anim/audio.py` | відтворення і годинник анімації за реальним часом |
| `midi_anim/visuals.py` | малювання об'єктів; кадр — функція від часу t |
| `midi_anim/hud.py` | легенда доріжок, журнал подій, смуга прогресу |
| `midi_anim/app.py` | головний цикл, клавіатура, миша, перетягування файлів |
| `tests/test_midi_parser.py` | тести переведення часу, зведення нот, ролей доріжок, розміру такту |
| `tests/test_sound_and_hud.py` | тести синтезатора (частота Найквіста, мікс) і формату часу |

Сторонні бібліотеки: **pygame** — вікно, графіка і відтворення звуку; **mido** — читання MIDI-повідомлень; **numpy** — синтез звуку.
